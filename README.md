# TripWise — Travel Discovery and Itinerary Planner

## About the Project
TripWise is a responsive travel discovery website that helps users explore destinations, search for cities, view destination details, and create a personal travel itinerary.

## Features
- Explore travel destinations through destination cards.
- Search destinations and cities using an external city API.
- Filter destinations by category.
- Sort destinations alphabetically or by rating.
- View detailed destination information.
- Add and remove destinations from My Trip.
- Save itinerary data in browser local storage.
- Responsive layout for desktop and mobile screens.
- Loading, error, and empty-result messages.

## Technologies Used
- HTML
- CSS
- JavaScript
- City search API: countries.dev
- Browser Local Storage
- GitHub Pages

## How to Run Locally
1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using the Live Server extension.
